### Problem Card #1

| Trường | Nội dung |
|---|---|
| Job Story | Khi đầu buổi lab nhận repo có 5 file hướng dẫn, tôi muốn nắm nhanh mình phải nộp gì, đặt tên thế nào và chỗ nào bị trừ điểm, để bắt tay vào làm ngay |
| Actor | Học viên K5 (chính); coach chấm bài (bị ảnh hưởng khi học viên nộp sai) |
| Thời điểm / bối cảnh | 15–30 phút đầu mỗi buổi lab, 2–3 lần/tuần |
| Quy trình hiện tại (3–7 bước) | 1. Đọc README (~5') → 2. Đọc RULES + CHECKPOINTS (~7') → 3. Mở RUBRIC, đối chiếu ngược với CHECKPOINTS xem phần nào nhiều điểm, phần nào bị trừ (~8') → 4. Đọc SUBMISSION để biết tên repo, tên file (~3') → 5. Tự ghi checklist việc cần làm (~2') |
| Bottleneck (bước nào, mất bao nhiêu phút) | Bước 3: nhảy qua lại giữa RUBRIC và CHECKPOINTS để ghép "checkpoint nào – nộp gì – bị trừ điểm khi nào", khoảng 8 phút. Cùng một quy định (ví dụ tên file) nằm rải ở 3 file khác nhau |
| Impact (nếu không giải thì sao) | Mất 30–90 phút/tuần cho mỗi người. Cả nhóm 3–4 người lặp lại cùng việc này. Hiểu sai một quy định có thể bị trừ 5 điểm (sai tên file/repo) hoặc 0 điểm một phần (thiếu TEAM.md) |
| Success metric (baseline → target) | Thời gian từ lúc mở repo đến lúc có checklist việc cần làm: 15–30 phút → dưới 10 phút. Đo bằng bấm giờ ở 3 lab tiếp theo. Phụ: số lỗi hình thức khi nộp giữ ở 0 |
| Phương án không dùng AI | Tự làm 1 file checklist mẫu (nộp gì, tên gì, trừ điểm khi nào) và dùng lại cho mỗi lab, vì các repo có cấu trúc giống nhau. Hoặc đề xuất coach để sẵn 1 trang "nộp gì trong 1 phút" ở đầu README |
| Giả thuyết về AI (nếu có) | AI đọc 5 file và xuất checklist theo checkpoint kèm điểm trừ. Nhưng nếu format các lab ổn định thì checklist mẫu (Rule) có thể đã đủ |
| Cảm nhận nhanh | Rule (checklist mẫu); có thể Workflow nếu mỗi lab khác nhau nhiều |

Quy trình nháp hiện tại:

```text
[Mở repo] → [1. Đọc README ~5'] → [2. Đọc RULES + CHECKPOINTS ~7']
          → [3. Đối chiếu RUBRIC ↔ CHECKPOINTS ~8'] ⚠ BOTTLENECK
          → [4. Đọc SUBMISSION ~3'] → [5. Ghi checklist ~2'] → [Bắt đầu làm]
Tổng: ~25 phút (dao động 15–30 phút)
```
